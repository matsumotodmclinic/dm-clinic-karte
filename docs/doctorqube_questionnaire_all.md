## 01. 糖尿病の事前問診(改訂版)

### 冒頭案内文(赤枠・太字)

> 成人(19歳以上)の糖尿病の方向けの問診票です。
> ・小学1年生〜高校3年生(18歳)までで1型糖尿病の方は「小児1型糖尿病の事前問診」からご予約ください。
> ・妊娠中・妊娠予定・産後フォローの方で血糖の異常を指摘された方は「妊娠糖尿病・糖尿病合併妊娠の事前問診」からご予約ください。

### 設問

**1. 受診の理由 ※必須・複数回答可**
- 症状がある
- 健診・人間ドックの結果から受診を勧められた
- 血縁者に糖尿病があるので調べたい
- 他の病院から当院を紹介された
- 現在通院中の医療機関から当院へ転院したい
- 引っ越し・転居のため
- その他(下記にご記入ください)
- 【その他・転院希望の詳しい理由】自由記載欄

**2. 現在通院中の医療機関について ※通院中の方のみ・任意**
- 医療機関名:自由記載

**2-2. 紹介状のご持参について ※任意【新規追加】**
- 当日お持ちになる予定はありますか:持参予定 / 持参しない・持っていない / わからない
  ※事前に分かると受付での準備ができます

**3. 自覚症状について ※必須**
- 体重減少の有無 ※**直近3か月で3kg以上**の減少がありましたか:あり / なし / わからない
  ※当院は「3か月で3kg以上」を体重減少と定義しています。設問文に必ずこの定義を入れてください。
  ※**「わからない」を必ず入れてください**(迷った方が「なし」を選ぶと見落としにつながるため)
- 【任意・より詳しく分かる方のみ】○か月間で○kg減少(数値入力)
  ※あくまで補足です。この欄の期間は3か月に限定しません
- その他の自覚症状(複数回答可):
  なし / のどが渇く / 尿の回数が多い / 体がだるい / 手のしびれ / 足のしびれ / 足がつりやすい / 視力が落ちた / 食後の低血糖を心配している / その他(自由記載)

**4. 現在の治療状況 ※必須・複数回答可**
- 食事療法のみ
- 内服薬(飲み薬)で治療中
- GLP-1受容体作動薬の注射
- インスリン注射で治療中
- まだ治療していない/検査中

**5. 診断されている疾患 ※複数選択可**
- 1型糖尿病と診断されたことがある
- 甲状腺の病気(バセドウ病、橋本病など)と診断されたことがある
- その他(自由記載)

**6. 直近の血液検査結果(お持ちの方のみ・任意)**
- HbA1c:数値入力(%)+ 測定年月プルダウン
- 血糖値:数値入力(mg/dL)+ 測定年月プルダウン

**7. 当院をどのようにして知りましたか? ※必須・複数回答可**
- インターネット
- 家族・知人の紹介
- 通りがかりに見かけた
- 医師の紹介
- バスの車内広告
- その他(自由記載)

### 【インスリン治療中の方へ】(折りたたみ枠)

> 該当される方のみご回答ください。
> 該当されない方は、そのまま最下部の【OK】ボタンまでお進みください。

**8. 現在、インスリン注射を使用していますか? ※単一選択**
- はい / いいえ

**9. デバイスの使用状況・ご希望について**

**◎ CGM(持続血糖測定器)について ※単一選択**
- 使用している → 機種:リブレ2 / G7 / その他(自由記載)
- 使用していない
- 関心がある/使ってみたい → 希望機種:リブレ2 / G7 / まだ分からないので教えてほしい

**◎ インスリンポンプ(CSII)について ※単一選択**
- 使用している → 機種:ミニメド / メディセーフウィズ / その他(自由記載)
- 使用していない
- 関心がある/使ってみたい → 希望機種:ミニメド / メディセーフウィズ / まだ分からないので教えてほしい

**◎ SAP(CGMと連動するポンプ)について ※単一選択**
- 使用している
- 使用していない
- 関心がある/使ってみたい

### 受診の流れ・ご案内(末尾表示)

> 【受診の流れ・ご案内】
> ・ご予約時刻の20分前にはご来院をお願いいたします。
> ・他院からの紹介状、検査結果、お薬手帳、血圧手帳をお持ちの方は受付で提出ください。
> ・ご予約日時には【事前採血】と【スタッフによる問診】を行います。
> ・その後、【医師の診察】は別日でのご案内となります。診察日の予約は、問診の際に設定いたします。
> ・症状により、初回予約日前に当院のスタッフからお電話させていただく場合があります。
